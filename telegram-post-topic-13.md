# Пост для Telegram: задание 13, IP-адреса

🧠 **Задание 13: решаем IP-адреса через `ipaddress`**

Разберём пример. Сеть задана адресом `192.168.32.160` и маской `255.255.255.240`. Сколько адресов в этой сети имеют чётное число единиц в двоичной записи?

В Python создаём сеть через стандартную библиотеку `ipaddress` и перебираем все адреса:

```python
from ipaddress import ip_network

network = ip_network('192.168.32.160/255.255.255.240')
answer = 0

for ip in network:
    bits = bin(int(ip))
    if bits.count('1') % 2 == 0:
        answer += 1

print(answer)
```

`ip_network` определяет диапазон сети по адресу и маске. `int(ip)` превращает адрес в число, `bin(...)` — в двоичную запись. Считаем единицы и проверяем, что их количество делится на 2. Цикл `for ip in network` включает все 16 адресов сети, в том числе адрес сети и широковещательный адрес: в условии спрашивают обо всех IP-адресах.

**Ответ: 8.**
