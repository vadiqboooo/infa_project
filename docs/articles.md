# Статьи и тесты к урокам

## Как пользоваться

1. Откройте **Админ-панель → Статьи → Создать статью**.
2. Введите название и текст в Markdown либо нажмите **«Загрузить HTML»** и выберите готовый `.html`/`.htm` файл. Можно также выбрать формат **HTML** и вставить код вручную. При загрузке файла пустое название заполняется из заголовка статьи. Кнопка «Предпросмотр текста» показывает результат.
3. При необходимости добавьте тест: один ответ, несколько ответов или «Верно / Неверно». Отметьте правильные варианты. Можно добавить пояснение для преподавателя; ученику оно не показывается.
4. Сохраните черновик или включите «Опубликовать». Ссылка ученика имеет вид `/articles/123`; для чтения нужен вход на платформу. Опубликованная статья доступна любому вошедшему ученику по ссылке.
5. Откройте **Группы → план уроков → добавить / изменить урок** и заполните нужные разделы:
   - **Теория** — статьи для чтения.
   - **Тестирование по теории** — тесты из статей, в которых добавлены вопросы.
   - **Решение на уроке** — один или несколько топиков.
   - **Домашняя работа** — один или несколько топиков, статьи и тесты. Для теста выберите тип материала **Тестирование**.
6. В каждом разделе выберите материал и нажмите `+`. Повторите для остальных материалов и сохраните урок. Чтобы ученики увидели материал, опубликуйте и статью, и урок.

На главной в плане отображается каждый прикреплённый материал с типом, названием урока, ссылкой и прогрессом. Пустые разделы не отображаются. Фильтр **Тесты** включает тесты на урок и на дом; фильтр **ДЗ** — все домашние материалы. Дедлайн относится только к домашней работе.

Кнопка загрузки примера в пустом тесте добавляет 10 вопросов «Как компьютер научился понимать буквы» с правильными ответами. Текст самой статьи нужно добавить отдельно.

## Вставка теста целиком

В редакторе статьи, в разделе **«Тест после статьи»**, нажмите **«Вставить тест целиком»**, вставьте текст и нажмите **«Добавить вопросы из текста»**. Вопросы добавляются в конец текущего теста; всего можно сохранить до 100 вопросов. Заголовок перед первым вопросом пропускается.

```text
1. Сколько цветов можно закодировать тремя битами?
A. 8
B. 6
Ответ: A

2. Какие данные могут храниться для пикселя? Выбери все подходящие варианты.
A. Цвет
B. Прозрачность
C. Название объекта
Ответ: A, B

3. Пиксель — элемент растрового изображения.
Верно
Неверно
Ответ: Верно
```

Поддерживаются номера `1.` и `1)`, латинские и русские буквы вариантов (`A.`, `B.`, `А)`, `Б)`). Каждый вариант начинается с новой строки. Текст вопроса и варианта может занимать несколько строк. Строка `Ответ:` необязательна; без неё правильные ответы нужно отметить вручную перед сохранением. Несколько указанных ответов или фраза «Выбери все подходящие варианты» включают тип «Несколько правильных ответов». Проверьте распознанные вопросы и нажмите **«Сохранить статью»**.

Проверка импорта: `cd client` → `node --test tests/article-quiz-import.test.mjs`.

## Прогресс

HTML сохраняется целиком, включая CSS, таблицы, схемы и встроенные изображения. При чтении текст получает общую журнальную типографику: колонка шириной до 720 px, шрифт с засечками и открытая вёрстка без карточки. Стили схем и таблиц сохраняются, оформление страницы адаптируется к светлой и тёмной темам. Скрипты и формы не выполняются. Изображения и внешние стили должны быть встроены в документ или доступны по абсолютным HTTP(S)-ссылкам: файлы из соседней папки на компьютере автоматически не загружаются. Лимит текста — 200 000 символов. Импорт заменяет текст, сохраняя вопросы теста; для публикации нужно нажать «Сохранить».

- Ученик отмечает статью прочитанной и получает доступ к тесту.
- Статья без теста завершается после отметки о прочтении.
- В тесте один балл даётся за полностью правильный ответ. Для множественного выбора нужны все правильные варианты без лишних.
- Вопросы показываются по одному: кнопка «Далее» и стрелки переключают карточки, выбранные ответы сохраняются при переключении. Счётчик и стрелки находятся над вопросом, текст занимает всю ширину карточки. После последнего вопроса кнопка «Проверить ответы» проверяет весь тест. Вместо вопросов отображаются итоговый балл и кнопка повторной попытки. Правильные варианты и пояснения не показываются и не передаются в ученическом ответе API. Ссылка на статью находится в описании теста.
- Тест завершается при 100% правильных ответов. Попытки не ограничены, сохраняются лучший результат и число попыток.
- В плане теория и тест учитываются отдельно: теория завершается после отметки о прочтении, тест показывает число правильных ответов. Ссылка теории открывает текст, ссылка теста — вопросы. Если статья ещё не прочитана, тест предлагает сначала перейти к теории.
- Если один тест назначен и на урок, и на дом, оба пункта показывают общий лучший результат ученика по этому тесту.
- Сохранение новой версии статьи сбрасывает актуальный прогресс: ученик должен пройти обновлённый материал. Ответы из старой открытой вкладки сервер отклоняет с просьбой обновить страницу.
- Черновики скрыты от учеников, включая ссылки из планов. Прикреплённую статью нельзя удалить, пока она используется в плане. Нельзя удалить все вопросы теста, если он назначен в плане.

## Обновление базы

Из каталога `server` выполните:

```powershell
python -m alembic upgrade head
```

Миграция `fc1e2f3a4b5c` создаёт таблицы статей и прогресса; `fd2f3a4b5c6d` добавляет формат содержимого; `fe3a4b5c6d7e` разделяет чтение и тестирование в плане. Существующие статьи сохраняют формат Markdown, прежние прикрепления статей учитываются как чтение. Docker запускает миграции автоматически перед сервером. Миграции нужно применить до запуска обновлённого API.

## Проверки

```powershell
# Из server; тесты используют отдельную SQLite в памяти
python -m pip install -r requirements-test.txt
python -m unittest discover -s tests -v

# Из client
npm.cmd run build
node --experimental-strip-types --test tests/group-preparation-plan.test.mjs
```

Тесты API покрывают доступ, публикацию, отсутствие ключей ответов в ученическом GET, проверку всех типов вопросов, повторные попытки, разделение результатов учеников, версии, четыре раздела плана, несколько топиков, домашние тесты и независимый прогресс чтения и тестирования.
